# Customer_Churn_Predictor_Model
Production-style customer churn prediction using Logistic Regression and Random Forest with clean pipelines, batch inference, and real-world ML practices.

## Dataset Information

This project uses data derived from the Hugging Face dataset:

- **Dataset**: d0r1h/customer_churn
- **Source**: https://huggingface.co/datasets/d0r1h/customer_churn
- **License**: Apache License 2.0

The original dataset has been cleaned and preprocessed for modeling.
The file `sample_input.csv` contains a small subset of rows for
demonstration and inference testing purposes only.

All credit for the original data collection goes to the dataset author.
